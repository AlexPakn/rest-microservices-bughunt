# Походження скриншотів pytest

PNG у `docs/screenshots/` — знімки локальних HTML-сторінок, зроблені браузером Microsoft Edge
через Playwright. Студентський звіт містить ці зображення безпосередньо біля відповідних дефектів.
Це знімки HTML-звіту, а не вікна термінала.

Кожна сторінка містить **дослівний stdout/stderr справжнього запуску pytest**,
команду, версію коду сервісів та код завершення процесу. Той самий вивід збережено
у відповідному `.txt`, а метадані — у `manifest.json`.
Один невдалий тест показано для кожного B01–B13. Додатково збережено загальний результат
початкової версії (53 failed, 3 passed) і виправленої (56 passed).

Початкові сервіси витягуються з тега `baseline` у тимчасову папку;
conftest читає її через `BUGHUNT_SOURCE_ROOT`. Самі тести не змінюються між прогонами.
Тимчасовий шлях у traceback може відрізнятися при повторному запуску.
Для B12 застосовано `--tb=line`, щоб помилка з'єднання була читабельною без довгого
стеку сторонніх бібліотек; для решти окремих помилок — `--tb=short`.

Повторне створення текстів та HTML (Python з установленими залежностями):

```powershell
python scripts/capture_pytest_evidence.py
```

Повторне створення PNG потребує Node.js, Playwright та Microsoft Edge:

```powershell
npm install --no-save playwright
node scripts/render_pytest_evidence.mjs
```

Для перегляду вже створених PNG встановлення Node.js не потрібне.
